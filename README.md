## 🌟 專案功能模組

### 1. 🌲 森林疾走 · 幸福加速賽 (`docs/forest-race.html`)
- **手機端連線互動**：支援多位親友掃描 QR Code 同時在線競技。
- **連擊奔跑機制**：高速點擊觸發「極速暴走」、粒子噴發與音效回饋。
- **新人默契搶答**：動態題目彈窗，答對獲得連續 3 秒高速自動狂奔推進。
- **30 秒迷霧森林衝刺**：後台或大螢幕觸發「最後 30 秒倒數」，全場進入迷霧森林背景，所有點擊推進威力瞬間提升 **300% (3X 狂暴暴走)**！
- **Firebase Realtime Database 即時同步**：毫秒級資料庫即時更新分數、距離、選手狀態與倒數計時。

### 2. 📺 現場 16:9 大螢幕實況廣播 (`docs/screen.html`)
- **會場大投影規格**：專為 16:9 大螢幕與投影機設計，晨曦森林賽道與即時多跑道選手衝刺。
- **即時排行榜**：即時百人賽況即時排序與動態換位。
- **30 秒迷霧全場狂暴廣播**：大螢幕即時切換森林迷霧視覺，動態飄霧與狂暴警報音效。
- **奧林匹克榮耀頒獎台**：競賽結束自動彈出前三名（冠、亞、季軍）與排名前十位榮譽跑者。

### 3. 💌 12/12 結婚喜帖 · 正式電子邀請函
- **官方正式喜帖網址**：[https://barry-winnie.pages.dev/](https://barry-winnie.pages.dev/)
- **會場資訊**：2026.12.12（六）桃園中壢 Amour 阿沐婚宴會館（E 廳）。
- **紙本長條折卡設計稿**：[`docs/invitation.html`](https://bringbowl.github.io/wedding-engagement/invitation.html) 支援手機模擬折疊正視圖與完整展開正反雙面印刷預覽。
